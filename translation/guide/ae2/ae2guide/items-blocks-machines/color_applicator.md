# 染色器

<ItemImage id="color_applicator" scale="4" />

染色器用來替可上色的方塊上色，例如[線纜](cables.md)、羊毛、陶土、玻璃與混凝土。
它消耗[顏料彈](paintballs.md)或染料；雪球則可以用來洗掉線纜上的顏色，以及方塊上的顏料彈污漬。

它的電力可以在 <ItemLink id="charger" /> 裡補充。

染色器的行為和[儲存單元](storage_cells.md)類似，要替它補顏料，最省事的方式是把它插進
<ItemLink id="chest" /> 的儲存單元欄位。

使用方式是右鍵上色，潛行滾動滑鼠滾輪則可以在存放的顏料彈與染料之間切換。

## 升級

染色器支援以下[升級卡](upgrade_cards.md)，透過 <ItemLink id="cell_workbench" /> 裝入：

*   <ItemLink id="equal_distribution_card" /> 讓每個類型分到相同的單元位元組空間，避免某一種把整個單元佔滿
*   <ItemLink id="void_card" /> 在單元裝滿時（若裝了平均分配卡，則是該類型的配額用完時）把送進來的物品銷毀。用它記得先設好分區！
*   <ItemLink id="energy_card" /> 用來提高它的電池容量
