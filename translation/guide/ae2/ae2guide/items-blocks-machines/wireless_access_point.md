# 無線存取點

<BlockImage id="wireless_access_point" p:state="has_channel" scale="8" />

讓你能用 <ItemLink id="wireless_terminal" /> 進行無線存取。
範圍與耗電取決於安裝的 <ItemLink id="wireless_booster" /> 數量。

一個網路上可以放任意數量的無線存取點，每一台裡也可以放任意數量的
<ItemLink id="wireless_booster" />，讓你透過調整配置來取捨耗電與範圍。

需要一條[頻道](../ae2-mechanics/channels.md)。

它同時也用來綁定[無線終端機](wireless_terminals.md)

# 無線訊號增幅卡

<ItemImage id="wireless_booster" scale="2" />

用來提升無線存取點的範圍。
