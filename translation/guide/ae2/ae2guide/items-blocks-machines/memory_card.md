# 記憶卡

<ItemImage id="memory_card" scale="4" />

記憶卡用來在 AE2 [裝置](../ae2-mechanics/devices.md)之間複製與貼上設定，也用來連結
[P2P 通道](p2p_tunnels.md)。它同樣能把[升級卡](upgrade_cards.md)貼進裝置裡。

- 潛行右鍵可以複製設定，或產生一組新的 P2P 連結頻率。
- 右鍵則是貼上設定、升級卡或連結頻率。
