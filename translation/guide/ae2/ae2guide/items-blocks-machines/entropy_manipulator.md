# 熵能機械臂

<ItemImage id="entropy_manipulator" scale="4" />

熵能機械臂讓你用右鍵加熱、潛行右鍵冷卻各種東西。它能做的事不多，
大致就是把水蒸發或凍結、把岩漿凝固成黑曜石、把原木燒成木炭，以及在世界中直接把鵝卵石燒成石頭。

如果對某個方塊沒有特定效果，它就會當成打火石使用。

它的電力可以在 <ItemLink id="charger" /> 裡補充。
