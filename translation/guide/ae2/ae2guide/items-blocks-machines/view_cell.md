# 檢視單元

<ItemImage id="view_cell" scale="2" />

檢視單元用來過濾[終端機](terminals.md)顯示的內容。你可以在 <ItemLink id="cell_workbench" /> 裡替它分區設定。

舉例來說，假設你想讓某台終端機只顯示某幾種石造建材，就把檢視單元分區設成那些材料再放進終端機，
畫面上就只會出現那些物品。

檢視單元的效果是相加的：如果你有一個設定為橡木木材的檢視單元，和一個設定為鵝卵石的檢視單元，
兩個都放進去就會同時顯示木材與鵝卵石。
