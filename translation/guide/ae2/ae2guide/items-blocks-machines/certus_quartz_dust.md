# 賽特斯石英粉

<ItemImage id="certus_quartz_dust" scale="4" />

<ItemLink id="certus_quartz_crystal" /> 碾碎後的粉末。用於製作多種 AE2 材料與元件。

## 配方

**本翻譯包修正**：原文說是用 <ItemLink id="inscriber" /> 壓碎的，但 LIA 移除了那條配方，改成：

*   機械動力的石磨：賽特斯石英水晶 → 90% 機率得到賽特斯石英粉
*   Thermal 的粉碎機：賽特斯石英水晶 → 賽特斯石英粉

這兩種機器的配方圖指南畫不出來，所以此處沒有配方圖，請在 JEI 裡查。
